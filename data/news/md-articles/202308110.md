# Welcome to SJA Analyzer!

Welcome to SJA Plus, a major update after the Scratch edition. SJA Plus offers faster, more detailed and more flexible analysis of Scratch projects.

SJA originally stood for Scratch Json Analyzer. The name was shortened after the analyzer became widely used.

The Scratch and original Python editions revealed many issues and brought valuable feedback. I decided to rebuild the analyzer to address these issues and improve the experience. Project comparison was the original motivation, while analysis helped introduce the tool. As demand changed, the focus shifted toward project analysis.
